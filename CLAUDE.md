# Кастомные правила разработки (Мой Стиль)

## Окружение и Терминал
- ОС: CachyOS (Arch-based). Командная оболочка: Fish.
- ВАЖНО: Пиши команды терминала строго с учетом синтаксиса Fish. Не используй bash-специфичные конструкции, которые могут упасть в Fish.

## Стек и Архитектура компонента
- Фронтенд: Next.js (App Router) + TypeScript.
- Стилизация: ТОЛЬКО модульный Sass (`*.module.scss`). Никакого Tailwind.
- Верстка: Строго Mobile First, адаптивная, чистая. Все шрифты и размеры — без "магических чисел".

## Высший пилотаж (Паттерны)
- Все базовые интерактивные элементы (кнопки, ссылки) должны быть ПОЛИМОРФНЫМИ. Используй паттерн `as` prop, чтобы один и тот же компонент по кнопке `as={Link}` мог рендериться как ссылка Next.js, сохраняя Sass-стили.
- Для сложных узлов (Табы, Модалки) ВСЕГДА используй паттерн Compound Components (Составные компоненты через React Context). Компоненты управления (Triggers) и панели контента (Content) должны иметь возможность свободно располагаться в разных частях DOM-дерева.

## Поведение агента
- Перед финальной сдачей кода всегда проверяй типы (`tsc`) и запускай линтер проекта.
